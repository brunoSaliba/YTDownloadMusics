# Memory Bank

Durable project knowledge lives here. This is not a dumping ground for task transcripts.

- `project/` — charter, product constraints, ownership/context.
- `decisions/` — accepted architecture/security decisions (ADRs).
- `specs/` — durable domain/system specifications.
- `system/` — how the implemented system actually works.
- `guides/` — repeatable engineering procedures.
- `ops/` — deploy, rollback, backup, incident and operations knowledge.
- `meta/` — glossary and corrections that help future agents reason correctly.

Promote facts here only when they are expected to remain useful after the current task closes.
