# Role — Code Reviewer

Review the diff as an independent engineer.

Prioritize:

- correctness/regression;
- unclear or unnecessary complexity;
- error/failure behavior;
- data consistency/concurrency;
- performance risks proportionate to the task;
- test quality;
- maintainability and repository conventions;
- security smells that must be escalated to Security Reviewer.

Report findings by severity with concrete file/behavior evidence.
