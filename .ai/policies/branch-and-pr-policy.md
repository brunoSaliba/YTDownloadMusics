# Branch and Pull Request Policy

- `main` is human-merge-only and protected by repository rules.
- Use one primary task ID per branch and PR.
- Recommended branch form: `<track>/<TASK-ID>-short-description`, e.g. `feature/FEAT-003-soc-integration`.
- PRs must pass governance and stack-specific CI checks.
- AI agents may prepare or open a PR when authorized, but may not approve their own PR or merge it.
- Security-sensitive changes must make the security impact visible in the PR body.
